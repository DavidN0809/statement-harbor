Welcome to PaperPull

Two steps. Choose where your downloads will live, then tick the providers you have accounts with. A folder is set up for each one, and nothing is downloaded until you ask.

/data is the container's name for its data folder. On your server it is the folder named data inside the folder that holds compose.yaml, unless your compose.yaml points it somewhere else. Each provider you tick gets a folder of its own in there, and its documents go in that folder.

Invented statements and receipts, so you can try the Status tab and both spreadsheets before you point this at a real account. Nothing is downloaded and nothing of yours is touched.

Already have PaperPull downloaders from before?

Paste the full path of the folder that holds them, the one with Chase Statements, Amazon Receipts and so on inside it. Nothing is moved or copied. This panel works on what is already there, and your existing way of running them keeps working too.

more

Verify re-checks every saved PDF. Diagnose reads the provider's page and writes two files to its Diagnostics folder, downloading nothing. The one whose name starts with survey- holds counts and states and no text from your account, and that is the one to attach to an issue. The detailed file beside it keeps a word only when it is on PaperPull's fixed list and writes any other as its shape, so it can go with it. A screenshot, where Diagnose takes one, shows the page as it is and stays on this machine.

Rename preview shows what this app would call the files you already have, and changes nothing. Apply renames then renames them where they sit. Nothing is downloaded either way, nothing moves between folders, and only files this app downloaded are touched.

1. Login opens a browser. Sign in yourself and leave it open.
2. Discover shows what the provider has for you and downloads nothing. It is optional, since Pilot and Run All look too.
3. Pilot tests the newest few.
4. Run All downloads everything you don't already have.

↻ Safe to re-run. Run All and Resume skip any statement or receipt you've already downloaded. Nothing is ever fetched twice, even if you deleted the PDFs after importing them elsewhere, unless you tick Download again under Scope.

Statements

    
The transactions inside your statement PDFs, one row
       each, with a Statements sheet that says whether every statement adds up. Each PDF is
       read once and remembered, so the first build takes a few minutes for a big archive and
       the next takes seconds. Money in is positive, money out is negative, for a bank account
       and a card alike. A statement that does not reconcile is still exported, with the
       difference shown, so you know which rows to doubt.

         {a|b} takes the first that has a value.
